--- title: Excel Alma Lookup tool_title: Excel Alma Lookup abstract: "An Alma batch-search plugin designed to be used within Microsoft Excel for Windows. When integrated with your local Alma instance, the tool can perform searches by keyword, call number, title, ISBN, ISSN, MMS ID and many other fields based on the spreadsheet data. Selected non-Alma catalogs can also be searched, such as WorldCat, Library of Congress, ReCAP, and BorrowDirect. The tool pulls out data from OCLC Connextion and Alma to Excel where other tasks can be carried out, for instance, transforming the data for digital platforms. Note: Requires SRU Server Type Integration Profile to be enabled in Alma." tool_url: https://github.com/pulibrary/ExcelAlmaLookup source_code: creator: Princeton University Library type: Plug-in category: - Extraction/Embedding - Transformation - Retrieval use_case: Extracting interface: GUI dependencies: Microsoft Excel; Windows OS open_source_proprietary: Open Source cost: Free related_tools: Excel metadata_standard: MARC file_format: resources: ---
